Recover your Emergency PIN

Answer at least 3 of the 5 personal questions you set at registration to set a new Emergency PIN. This is fully automated — no live agent is involved.

Enter the CNIC or phone number you registered with. We'll then show the 5 questions you set, and you'll need to answer at least 3 correctly.
Answer the questions you set at registration.
Each question you set is shown above its own answer box. Answers are matched against hashed values stored at registration. You'll be notified by email of this attempt regardless of outcome. A successful recovery lets you set a brand-new Emergency PIN — your old PIN can never be revealed, only replaced. (Demo: Ali's answers are "iPhone" / "March 2026" / "Karachi" / "blue" / "Askari 11".)
